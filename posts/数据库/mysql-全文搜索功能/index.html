简介#

全文搜索的含义引用维基百科的解释就是：

将用户随意输入的文字，试图从数据库中，找到符合的内容

我们常见的如字典，通过 目录 找到 具体内容 而使用的索引叫做——正向索引(forward index)

而全文搜索，则是反过来，通过 具体内容的关键字 来寻找 目录/完整的具体内容 ，这个反向过程使用到的索引我们称之为——倒排索引(inverted index)，一般来讲所谓的全文索引，可以直接理解为倒排索引，例如 Mysql 提供的 FULLTEXT 索引

基本原理#

假如一段具体内容 下雨天留客天天留我不留的唯一标识是 1，创建全文索引时，会先进行拆词。 可能拆成 下雨天、留客、天天留、我不留 也可能拆成 下雨天、留客、天、留我不、留 ……(根据不同的分词逻辑会拆成不同结果，进而影响全文搜索效果)

此处我们以 下雨天、留客、天天留、我不留 为例，则能创建出索引，记录 1 的这段内容出现了 下雨天、留客、天天留、我不留 各一次(记录出现次数，可以在若干段记录出现目标关键字时进行相关度排序)

如果我们搜索 下雨天 这个关键字，便可立即找到 1 对应的内容。当然此时如果你用 下雨 做关键词搜索，则显示没有符合条件的内容，不难得出，全文搜索的实际使用效果与分词结果有着密切关系(尤其相比英语，中文组字成词，具有更多的可能性和更多的语义，导致分词变成了地狱级难度)

深入的实现原理本文不再赘述，有兴趣可以研究全文搜索典例——Lucene

ngram 全文解析器#

创建全文索引时，使用到的 WITH PARSER ngram 是使用 ngram 全文解析器，创建全文索引时，请自行决定是否要追加 WITH PARSER ngram

ngram 全文解析器 是支持中文的语义分词工具，把它 调教 得好用是个很复杂的过程。使用 ngram 全文解析器 后，通常匹配到的结果会非常多。详情请自行查阅文档 12.9.8 ngram Full-Text Parser

调整其参数可能会涉及到改配置项，常见的配置项路径 /etc/mysql/mysql.conf.d/mysqld.cnf

查询内容#

全文索引查询时大致分为 4 类模式

  • IN NATURAL LANGUAGE MODE： 自然语言模式，未指定模式的话，这是默认值。用搜索字符去匹配全文索引值，对匹配相关性进行度量，返回搜索结果
  • IN NATURAL LANGUAGE MODE WITH QUERY EXPANSION： 它通过执行两次搜索来工作，其中第二次搜索会进行语义扩展解析，例如搜索关键字是 datebase，那么 mysql 、oracle…… 也会被解析为可以被匹配， 并与来自第一次搜索的少数几个最相关的文档连接在一起(建议忘记这个模式，未 调教 的情况下，这个功能对中文应该不太友好)
  • IN BOOLEAN MODE： 布尔搜索模式，可以用 + 表示包含，- 表示不包含去匹配搜索内容， 例如 SELECT * FROM articles WHERE MATCH (title,body) AGAINST ('+MySQL -YourSQL' IN BOOLEAN MODE); 表示检索包含单词 MySQL 但 不包含单词 YourSQL 的记录
  • WITH QUERY EXPANSION： 同 IN NATURAL LANGUAGE MODE WITH QUERY EXPANSION
